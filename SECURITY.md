# Security Policy

## Project status

AirConsole is an academic project under active development. It connects a shared TV or desktop browser with mobile controller browsers, so session isolation, network communication, input validation, and dependency security are important parts of the project.

The software is currently experimental, has not undergone a professional security audit, and may contain undiscovered vulnerabilities. Do not use it for sensitive data or in a production environment.

## Supported versions

Security fixes are applied to the latest revision of the `main` branch. Older commits, forks, and unpublished builds are not supported.

| Version | Supported |
| --- | --- |
| Latest `main` revision | Yes |
| Older revisions | No |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Use the repository's private security-reporting channel when it is available. Otherwise, contact a project maintainer privately through the contact information published by the [BevyOnYourTV organization](https://github.com/BevyOnYourTV). Include:

- A description of the vulnerability and its potential impact.
- The affected revision, component, browser, and device type.
- Reproduction steps or a minimal proof of concept.
- Any conditions required to exploit the issue.
- Suggested mitigations, if known.

Remove credentials, personal data, and unrelated session information from the report. Give the maintainers reasonable time to investigate and prepare a fix before making details public.

The team will make a reasonable effort to acknowledge the report, assess its impact, and communicate remediation progress as part of the academic development cycle.
